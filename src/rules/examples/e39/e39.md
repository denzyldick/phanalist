# E0039: Property Access on Null

E0039 reports property reads on values that can be null. It is the
null-property member of Phanalist's bounded formal verification family
(E0031-E0043). The family shares a Z3-backed engine that encodes path conditions
and values, so a finding comes with a solver-backed counterexample rather than a
heuristic guess.

## What it checks

- Property reads on null and nullable values
- Nullness narrowed by `if`, `switch`, `match`, `isset()`, and short-circuit
  conditions
- Nullsafe property access (`?->`) is treated as safe
- PHPDoc parameter, `@var`, and return contracts
- Constant-return, identity, and method summaries

## Model limits

E0039 shares the model limits, loop bounds, and interprocedural behavior
described in [E0031](../e31/e31.md).

## Configuration

```yaml
rules:
  E0039:
    php_version: "8.4"
```
