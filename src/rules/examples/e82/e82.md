# E0082: Dynamic extension loading

**In plain English:** `dl()` is used to load PHP extensions at runtime, which can introduce security risks and is disabled in most modern PHP configurations.

**Why it matters:** Dynamic extension loading can:
- Load malicious or unverified extensions
- Bypass security controls provided by the base PHP installation
- Cause instability or crashes if extensions are incompatible
- Is disabled by default in PHP 5.3+ (thread-safe builds) and removed in PHP 7.0+

## Bad

```php
dl('my_extension.so'); // loads extension at runtime
dl('php_mysql.dll');
```

## Good

```php
// Install extensions via the system package manager or PECL
// Enable them in php.ini instead of loading at runtime
// extension=my_extension.so
```

## What the rule checks

- `dl()` function calls anywhere in the code

## When it does not report

- No safe usage — `dl()` is always flagged

## How to fix

1. Install PHP extensions via your system package manager (apt, yum, brew) or PECL
2. Enable extensions in php.ini with the `extension=` directive
3. Remove all `dl()` calls from your code

## Configuration

E0082 is enabled by default and has no configuration options.
