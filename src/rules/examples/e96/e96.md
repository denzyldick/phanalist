# E0096: `create_function()`

**In plain English:** `create_function()` creates a function from a string at runtime. This is essentially `eval()` and has been removed in PHP 8.0+. If any part of the function string comes from user input, an attacker can execute arbitrary PHP code.

**Why it matters:** `create_function()` with user input is direct code injection:
- Attacker can execute arbitrary PHP code
- Full server compromise possible
- Function is deprecated/removed in modern PHP

## Bad

```php
$sort = $_GET['sort'] ?? '';
$func = create_function('$a, $b', "return \$a->$sort <=> \$b->$sort;");
```

## Good

```php
$sort = $_GET['sort'] ?? '';
$allowed = ['name', 'date', 'price'];
if (!in_array($sort, $allowed, true)) {
    http_response_code(400);
    exit;
}
usort($items, fn($a, $b) => $a->$sort <=> $b->$sort);
```

## What the rule checks

- `create_function()` calls with any argument (function is inherently dangerous)

## When it does not report

- No safe usage — always flagged
- `create_function()` is removed in PHP 8.0+, but still present in legacy codebases

## How to fix

1. Replace with anonymous functions (closures)
2. Use arrow functions (PHP 7.4+)

## Configuration

E0096 is enabled by default and has no configuration options.
