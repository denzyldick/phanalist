# E0119: `expose_php = On`

**In plain English:** `expose_php = On` adds `X-Powered-By: PHP/version` header to every response, revealing the PHP version to attackers.

**Why it matters:** Version disclosure helps attackers target version-specific vulnerabilities.

## Bad

```php
ini_set('expose_php', '1');
// or php.ini: expose_php = On
```

## Good

```php
ini_set('expose_php', '0');
// or php.ini: expose_php = Off
// Also remove via web server config (Apache: ServerTokens Prod; Nginx: server_tokens off)
```

## What the rule checks

- `ini_set('expose_php', '1')` / `ini_set('expose_php', 'true')`
- Cannot read php.ini directly

## When it does not report

- `expose_php` is PHP_INI_SYSTEM — cannot be changed at runtime via `ini_set()` in most contexts
- Web server headers (`Server`, `X-Powered-By`) also need server-level configuration

## How to fix

1. Set `expose_php = Off` in php.ini
2. Configure web server to not expose version headers
3. Use `headers_remove('X-Powered-By')` in PHP as a partial mitigation

## Configuration

E0119 is enabled by default and has no configuration options.
