# E0100: Variable function call

**In plain English:** A function is called using a name that comes from user input, allowing an attacker to invoke arbitrary PHP functions on your server.

**Why it matters:** Variable function calls allow dynamic code execution if the function name is controllable by an attacker:
- Call arbitrary PHP functions
- Call dangerous system functions like `system()`, `exec()`, `shell_exec()`
- Bypass access controls

## Bad

```php
$func = $_GET['func'] ?? '';
$func();
call_user_func($func, $arg);
```

## Good

```php
$func = $_GET['func'] ?? '';
$allowed = ['strlen', 'md5', 'sha1'];
if (!in_array($func, $allowed, true)) {
    http_response_code(400);
    exit;
}
$func($input);
```

## What the rule checks

- `$func()` where `$func` is assigned from tainted superglobals
- `call_user_func($func, ...)` where `$func` is tainted
- `call_user_func_array($func, ...)` where `$func` is tainted

## When it does not report

- Whitelist validation is recognized
- Static function names are not flagged

## How to fix

1. Use a whitelist/dispatch table of allowed functions
2. Never call user-supplied function names directly

## Configuration

E0100 is enabled by default and has no configuration options.

## Taint Engine Backed

This rule is now powered by the phanalist taint engine. Instead of guessing whether
a variable contains user input (`has_user_input` / `looks_dynamic` heuristics), the
engine performs source-to-sink taint tracking. The rule queries `SinkKind` from the
engine:

- **`TaintMode::Only`** (default): Only reports when a proven taint flow from a source
  (e.g. `$_GET`, `$_POST`, superglobals, request parameters) reaches the sink.
- **`TaintMode::Annotate`**: Reports all findings and adds the proven source origin.
- **`TaintMode::Off`**: Retains the legacy heuristic behaviour through
  `taint_support::looks_dynamic` for compatibility.

Every finding carries structured metadata (severity, category, confidence, effort,
CWE/OWASP references, fingerprint) and a stable content-based fingerprint independent
of line numbers.
