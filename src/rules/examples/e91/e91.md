# E0091: `wddx_deserialize()`

**In plain English:** `wddx_deserialize()` deserializes WDDX (Web Distributed Data Exchange) packets. WDDX is an older XML-based data serialization format. Like `unserialize()`, it can instantiate PHP objects and lead to object injection.

**Why it matters:** WDDX deserialization is a known object injection vector. Attackers can:
- Instantiate arbitrary PHP classes
- Trigger magic methods (`__wakeup()`, `__destruct()`)
- Achieve object injection and potentially remote code execution

## Bad

```php
$data = $_GET['wddx'] ?? '';
$result = wddx_deserialize($data);
```

## Good

```php
// Use JSON instead of WDDX
$result = json_decode($_GET['json'] ?? '', true);
```

## What the rule checks

- `wddx_deserialize()` calls with any argument (function is inherently dangerous)

## When it does not report

- No safe usage of `wddx_deserialize()` with untrusted input — always flagged

## How to fix

1. Replace WDDX with JSON (`json_decode()` / `json_encode()`)
2. If WDDX is required, validate and allowlist before deserialization

## Configuration

E0091 is enabled by default and has no configuration options.
