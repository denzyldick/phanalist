# E0031: Formal Verification

E0031 uses a bounded formal analysis to prove safety properties about PHP code
and to produce a counterexample when a property can be violated.

## What it checks

- Division, modulo, and `intdiv()` by zero
- `intdiv()` overflow (`PHP_INT_MIN / -1`)
- Negative or out-of-bounds array indexes and string offsets
- Null method calls and property reads
- Return values that contradict their declared return contract or PHPDoc `@return` contract
- PHPDoc `@param` refinements such as `positive-int`, `non-zero-int`, and `int<min, max>`, including `@phpstan-*` and `@psalm-*` variants
- Unreachable statements after `return`, `break`, `continue`, `throw`, or `exit`
- Assertions that can never hold, and assertions that narrow a later property
- Division and access inside `switch` cases and `match` arms, with case guards and fallthrough

## Configuration

```yaml
rules:
  E0031:
    php_version: "8.4"
    check_division: true
    check_modulo: true
    check_intdiv: true
    check_array_index: true
    check_string_offset: true
    check_nullability: true
    check_types: true
    check_assertions: true
    check_unreachable: true
    check_return_contracts: true
    loop_strategy: auto
    unroll_depth: 16
    timeout_ms: 1000
    unknown_policy: report
    max_findings_per_function: 50
```

The verifier is conservative: when it cannot model a value or operation exactly,
it reports the property as unverified instead of claiming it is safe.
