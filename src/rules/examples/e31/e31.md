# E0031: Formal Verification

E0031 uses a bounded formal analysis to prove safety properties about PHP code
and to produce a counterexample when a property can be violated.

## What it checks

- Division, modulo, and `intdiv()` by zero
- `intdiv()` overflow (`PHP_INT_MIN / -1`)
- Negative or out-of-bounds array indexes and string offsets
- Null method calls and property reads
- Return values that contradict their declared return contract or PHPDoc `@return` contract
- PHPDoc `@param` and `@var` refinements such as `positive-int`, `non-zero-int`, and `int<min, max>`, including `@phpstan-*` and `@psalm-*` variants
- `@phpstan-assert` and `@psalm-assert` contracts on functions and methods
- Unreachable statements after `return`, `break`, `continue`, `throw`, or `exit`, including numbered levels and `continue` inside `switch`
- Assertions that can never hold, and assertions that narrow a later property
- Division and access inside `switch` cases and `match` arms, with case guards and fallthrough
- Bounded unrolling of `while`, `for`, `do`/`while`, and `foreach` loops, including literal-array key/value targets
- Closures and arrow functions, including values captured with `use`
- `try`/`catch`/`finally` blocks, including catches and finally blocks after early returns
- `never` return contracts on functions and methods, making following code unreachable
- `strlen()` and `count()` when their inputs are known, including derived string and array indexes
- Constant-return function and method summaries, plus identity summaries for untyped parameters, including `self::`, `static::`, `parent::`, and `$this->` calls, resolved through class and function `use` imports, aliases, and group imports
- Inherited methods through `extends` and trait `use`, including cross-file inheritance

## Configuration

```yaml
rules:
  E0031:
    php_version: "8.4"
    check_division: true
    check_modulo: true
    check_intdiv: true
    check_array_index: true
    check_string_offset: true
    check_nullability: true
    check_types: true
    check_assertions: true
    check_unreachable: true
    check_return_contracts: true
    loop_strategy: auto
    unroll_depth: 16
    timeout_ms: 1000
    unknown_policy: report
    max_findings_per_function: 50
```

`check_types` controls PHP parameter type hints and PHPDoc `@param`/`@var`
refinements. `php_version` is accepted for configuration compatibility; the
modelled semantics are the same across PHP 8.0–8.4.

The verifier is conservative: when it cannot model a value or operation exactly,
it reports the property as unverified instead of claiming it is safe.
