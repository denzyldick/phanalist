# E0085: Inline PHP execution short tags

**In plain English:** Short echo tags `<?= ?>` are used in production code. While generally harmless in modern PHP, they can be disabled via `short_open_tag = Off` in php.ini, causing your code to break or be output as plain text.

**Why it matters:** Short tags can cause:
- PHP source code being served as plain text if `short_open_tag` is disabled
- Portability issues across different server configurations
- Confusion with XML declarations (`<?xml ... ?>`)

## Bad

```php
<?= $userInput ?>
<?= $variable ?>
```

## Good

```php
<?php echo $userInput; ?>
<?php echo htmlspecialchars($variable, ENT_QUOTES, 'UTF-8'); ?>
```

## What the rule checks

- `<?= ... ?>` short echo tags in PHP files
- `<?` short open tags (without `php`)

## When it does not report

- Files known to run on servers with `short_open_tag = On`
- Cannot detect server-level php.ini configuration

## How to fix

1. Replace `<?= ... ?>` with `<?php echo ...; ?>`
2. Always escape output with `htmlspecialchars()` for HTML contexts
3. Set `short_open_tag = Off` in php.ini and use full tags

## Configuration

E0085 is enabled by default and has no configuration options.
