# E0026: Comment Ratio

Reports classes whose comment ratio is below the configured minimum or above the configured maximum.

## Why it matters

Comments can provide useful context, but too few or too many can both be signals of maintenance problems. Very low comment coverage may leave intent unclear; very high comment coverage can indicate code that is hard to follow.

## What it checks

- Applies to class declarations.
- Scans raw file lines and classifies them as code, comment, or blank.
- Calculates ratio as `comment_lines / (code_lines + comment_lines)`.
- Reports `E0026:undercommented` when ratio is below `min_ratio`.
- Reports `E0026:overcommented` when ratio is above `max_ratio`.

## Bad example: too few comments

```php
class PaymentProcessor
{
    public function execute(): void
    {
        $this->validate();
        $this->charge();
        $this->notify();
    }
}
```

## Bad example: too many comments

```php
class PaymentProcessor
{
    /**
     * Processes a payment by validating, charging, and notifying.
     * This method is the main entry point for payment processing.
     * It orchestrates the three step payment workflow.
     */
    public function execute(): void
    {
        // Step 1: Validate the payment input
        $this->validate(); // Check if the input data is valid
        // Step 2: Charge the customer
        $this->charge(); // Process the payment with the gateway
        // Step 3: Notify the customer
        $this->notify(); // Send the confirmation email
    }
}
```

## Good example

Comments explain intent, while the code remains clear.

```php
/**
 * Processes payments through the configured gateway.
 * Supports credit cards and wire transfers.
 */
class PaymentProcessor
{
    public function execute(): void
    {
        $this->validate();
        $this->charge();
        $this->notify();
    }
}
```

## How to fix

- **Undercommented**: add concise comments where intent, constraints, or tradeoffs are not obvious from the code.
- **Overcommented**: simplify naming and structure so the code explains itself, and keep comments for non-obvious decisions.

## Configuration

```yaml
rules:
  E0026:
    min_ratio: 0.05
    max_ratio: 0.5
```
