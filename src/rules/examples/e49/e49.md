# E0049: Invalid Builtin Argument

E0049 reports builtin calls whose literal arguments are invalid and would make
PHP throw a `ValueError` at runtime.

## What it checks

- `str_repeat()` with a negative repeat count
- `array_fill()` with a negative count
- `range()` with a zero step
- `str_split()` and `mb_str_split()` with a non-positive chunk length
- `explode()` with an empty delimiter
- `array_chunk()` with a non-positive chunk size
- `array_combine()` with literal arrays of different lengths
- `random_int()`, `mt_rand()`, and `rand()` with a minimum greater than the
  maximum

The rule only reports values it can prove from literals, including unary minus,
parenthesized literals, and literal array lengths. Non-literal arguments are
ignored so the rule does not duplicate runtime type analysis.

## Model limits

- Only direct calls to the named builtins are checked.
- Named arguments are matched by their source order, not by parameter name.
- Array lengths are known only for literal arrays without missing or variadic
  elements.
- Integer values that do not fit in `i64` are ignored.
- The rule does not evaluate constants, class constants, or expressions.

## Configuration

E0049 has no configuration options and is enabled by default.
