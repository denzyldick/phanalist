# E0086: Deprecated session function

**In plain English:** Deprecated session functions `session_register()`, `session_is_registered()`, or `session_unregister()` are used. These were removed in PHP 5.4 and cause fatal errors on modern PHP.

**Why it matters:** These functions no longer exist in PHP 5.4+, so any code using them will crash with a fatal error. Use the `$_SESSION` superglobal instead.

## Bad

```php
session_register('username');
$username = $_POST['username'] ?? '';
if (session_is_registered('username')) {
    // ...
}
session_unregister('username');
```

## Good

```php
$_SESSION['username'] = $_POST['username'] ?? '';
if (isset($_SESSION['username'])) {
    // ...
}
unset($_SESSION['username']);
```

## What the rule checks

- `session_register()`, `session_is_registered()`, `session_unregister()` function calls

## When it does not report

- `$_SESSION` superglobal usage is not flagged
- `session_start()`, `session_destroy()`, `session_regenerate_id()` are not flagged

## How to fix

1. Replace `session_register('var')` with `$_SESSION['var'] = ...`
2. Replace `session_is_registered('var')` with `isset($_SESSION['var'])`
3. Replace `session_unregister('var')` with `unset($_SESSION['var'])`

## Configuration

E0086 is enabled by default and has no configuration options.
