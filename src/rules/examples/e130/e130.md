# E0130: Command execution via passthru

**In plain English:** `mysqli_multi_query()` executes multiple SQL statements. If user input reaches it, an attacker can append additional queries.

**Why it matters:** Stacked queries allow data modification, DROP TABLE, and other destructive operations beyond SELECT.

## Bad

```php
$id = $_GET['id'] ?? '';
mysqli_multi_query($conn, "SELECT * FROM users WHERE id = $id; DROP TABLE users;");
```

## Good

```php
$id = (int)($_GET['id'] ?? 0);
$stmt = $pdo->prepare("SELECT * FROM users WHERE id = ?");
$stmt->execute([$id]);
```

## What the rule checks

- `mysqli_multi_query()` with tainted input
- `mysqli::multi_query()` with tainted input
- Multiple statements in a single query string with taint

## When it does not report

- Single-statement prepared statements are safe
- `mysqli_query()` (single statement) is covered by E0060

## How to fix

1. Never use `mysqli_multi_query()` with user input
2. Use prepared statements for individual queries

## Configuration

E0130 is enabled by default and has no configuration options.
