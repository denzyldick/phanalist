# E0111: Deprecated mysql extension

**In plain English:** Removed `ext/mysql` extension functions (`mysql_connect()`, `mysql_query()`, etc.) are used. These were removed in PHP 7.0 and cause fatal errors.

**Why it matters:** The original `ext/mysql` extension was removed in PHP 7.0. Any code using these functions will crash with a fatal error on PHP 7.0+. The extension also lacks support for prepared statements, making it inherently vulnerable to SQL injection.

## Bad

```php
$conn = mysql_connect('localhost', 'user', 'pass');
mysql_select_db('mydb', $conn);
$result = mysql_query("SELECT * FROM users WHERE id = $id");
mysql_fetch_assoc($result);
```

## Good

```php
// Use PDO or MySQLi with prepared statements
$pdo = new PDO('mysql:host=localhost;dbname=mydb', 'user', 'pass');
$stmt = $pdo->prepare("SELECT * FROM users WHERE id = ?");
$stmt->execute([$id]);
$user = $stmt->fetch();
```

## What the rule checks

- `mysql_connect()`, `mysql_pconnect()`, `mysql_select_db()`, `mysql_query()`, `mysql_fetch_assoc()`, `mysql_fetch_array()`, `mysql_num_rows()`, `mysql_real_escape_string()`, `mysql_error()`, `mysql_errno()`
- Any function with the `mysql_` prefix (except `mysqlnd` which is a driver, not the extension)

## When it does not report

- `mysqli_*` and `PDO_*` functions are not flagged
- `mysqlnd` references (native driver) are not flagged

## How to fix

1. Replace `mysql_*` functions with PDO or MySQLi
2. Use prepared statements with parameter binding
3. Update your codebase to support PHP 7.0+

## Configuration

E0111 is enabled by default and has no configuration options.
