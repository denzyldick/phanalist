# E0003: Method modifiers

Methods in classes should declare an explicit visibility modifier: `public`, `protected`, or `private`.

## Why it matters

Without an explicit modifier, it is less clear whether a method is intended for external use or internal class behavior. Explicit visibility makes the class interface easier to understand and supports encapsulation.

## Bad example

```php
class Calculator {
    // Missing visibility modifier.
    function add(int $a, int $b): int {
        return $a + $b;
    }
}
```

## Good example

```php
class Calculator {
    public function add(int $a, int $b): int {
        return $a + $b;
    }
}
```

## What it checks

- Class methods that do not declare `public`, `protected`, or `private`.

## When it does not report

- When every method has an explicit visibility modifier.

## How to fix

Add the appropriate visibility modifier to each method definition.

## Configuration

E0003 has no configuration options and is enabled by default.
