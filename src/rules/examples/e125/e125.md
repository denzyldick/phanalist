# E0125: Missing `Permissions-Policy`

**In plain English:** No `Permissions-Policy` header, allowing the browser to enable powerful features (camera, microphone, geolocation) without explicit policy.

**Why it matters:** Without restrictions, malicious third-party scripts on your page can access sensitive browser features.

## Bad

```php
// No Permissions-Policy header
header("Content-Type: text/html");
echo $page;
```

## Good

```php
header("Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=()");
header("Content-Type: text/html");
echo $page;
```

## What the rule checks

- PHP scripts sending HTML without `Permissions-Policy` header

## When it does not report

- Cannot detect Permissions-Policy set at web server level

## How to fix

1. Send `Permissions-Policy` header disabling features you don't use
2. Start with `camera=(), microphone=(), geolocation=()` and add as needed

## Configuration

E0125 is enabled by default. Configuration options:

```yaml
rules:
  E0125:
    exclude_paths:
      - api/
```

Browser feature policy. Modern privacy/security header.
