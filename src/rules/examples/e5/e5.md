# E0005: Capitalized class name

Class names should start with an uppercase letter, typically using PascalCase (StudlyCase).

## Why it matters

PHP naming conventions and PSR-4 autoloading expect class names to start with an uppercase letter. Consistent naming makes class references easier to recognize and keeps code predictable.

## Bad example

```php
class paymentProcessor {
    // ...
}
```

## Good example

```php
class PaymentProcessor {
    // ...
}
```

## What it checks

- Class declarations.
- Whether the first letter of the class name is uppercase.

## When it does not report

- When the class name starts with a capital letter, such as `PaymentProcessor` or `UserRepository`.

## How to fix

- Capitalize the first letter of the class name.
- If your project uses PSR-4 or similar conventions, make sure the file name matches the class name.

## Configuration

E0005 has no configuration options and is enabled by default.
