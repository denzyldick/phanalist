# E0005: Capitalized class name

**In plain English:** Class names (and by extension interfaces, traits, and enums) should start with an uppercase letter (PascalCase / StudlyCase).

**Why it matters:** PSR-4 autoloading and PHP standards convention rely on class names starting with an uppercase letter to distinguish class references from functions or variables. It keeps the codebase consistent and predictable.

## ❌ The Bad Example
```php
class paymentProcessor {
    // ...
}
```

## ✅ The Good Example
```php
class PaymentProcessor {
    // ...
}
```

## What the rule checks
- Inspects the declaration of every PHP class.
- Verifies that the first letter of the class name is uppercase (`is_uppercase()`).

## When it does not report
- When the class name starts with a capital letter (`PaymentProcessor`, `UserRepository`, etc.).

## How to fix
- Capitalize the first letter of the class name.
- Ensure the filename matches the class name according to your project's naming conventions (e.g., `PaymentProcessor.php`).

## Configuration
E0005 has no configuration options and is enabled by default.

### Junior Engineer's Rule of Thumb:
Functions and variables are camelCase (`getUser`). Classes are PascalCase (`UserProcessor`). Always capitalize your class names!
