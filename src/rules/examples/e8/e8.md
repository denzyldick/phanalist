# E0008: Return type signature

Methods should declare an explicit return type, such as `: int`, `: string`, `: void`, or `: ?User`.

## Why it matters

Return type declarations make a method's contract clearer. They help readers understand what to expect and allow PHP and static analysis tools to catch type mismatches earlier.

## Bad example

```php
class UserService {
    // Missing return type signature.
    public function getUser($id) {
        return $this->repository->find($id);
    }
}
```

## Good example

```php
class UserService {
    public function getUser(int $id): ?User {
        return $this->repository->find($id);
    }
}
```

## What it checks

- Method declarations that are missing a return type.

## When it does not report

- When a method declares an explicit return type, including `: void`, `: mixed`, or union types.

## How to fix

Add the appropriate return type to the method signature.

## Configuration

E0008 has no configuration options and is enabled by default.
