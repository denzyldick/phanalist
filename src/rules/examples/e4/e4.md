# E0004: Uppercase constants

Constants should use uppercase letters with underscores, such as `MAX_RETRIES`.

## Why it matters

PHP constants are immutable values. Using an all-uppercase naming convention makes constants easy to distinguish from variables and other identifiers.

## Bad example

```php
define('max_retries', 3);

class Config {
    public const timeoutSeconds = 30;
}
```

## Good example

```php
define('MAX_RETRIES', 3);

class Config {
    public const TIMEOUT_SECONDS = 30;
}
```

## What it checks

- Global constants defined with `define()`.
- Constants defined inside classes, interfaces, traits, and enums.
- Whether constant names match their uppercase form.

## When it does not report

- When constant names are fully uppercase, such as `MAX_RETRIES` or `TIMEOUT_SECONDS`.

## How to fix

- Rename the constant to use uppercase letters and underscores.
- Update all references to that constant.

## Configuration

E0004 has no configuration options and is enabled by default.
