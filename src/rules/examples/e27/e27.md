# E0027: God Class

Reports classes, traits, or enums that have too many methods and too many fields, which can indicate a God Class.

## Why it matters

A type with many responsibilities is harder to understand, test, and change safely. Splitting it into focused types usually reduces coupling and makes behavior easier to maintain.

## What it checks

- Counts methods and properties in classes, traits, and enums.
- Reports when **both** thresholds are exceeded:
  - `method_count > max_methods`
  - `field_count > max_fields`

## Bad example

This class combines multiple responsibilities.

```php
class OrderManager
{
    private Database $db;
    private Cache $cache;
    private Logger $log;
    private Mailer $mail;
    // ... 7 more properties ...

    public function createOrder(): void { /* ... */ }
    public function updateOrder(): void { /* ... */ }
    public function cancelOrder(): void { /* ... */ }
    public function createUser(): void { /* ... */ }
    public function blockUser(): void { /* ... */ }
    public function generateReport(): void { /* ... */ }
    public function processRefund(): void { /* ... */ }
    public function sendInvoice(): void { /* ... */ }
    public function updateInventory(): void { /* ... */ }
    public function sendNotification(): void { /* ... */ }
    public function clearCache(): void { /* ... */ }
    public function writeAuditLog(): void { /* ... */ }
    // ... more methods ...
}
```

## Good example

Responsibilities are split into focused classes.

```php
class OrderService
{
    public function __construct(
        private OrderRepository $orders,
        private BillingService $billing,
    ) {}

    public function create(Cart $cart): Order { /* ... */ }
    public function cancel(Order $order): void { /* ... */ }
}

class UserService
{
    public function __construct(
        private UserRepository $users,
    ) {}

    public function register(string $email): User { /* ... */ }
    public function block(User $user): void { /* ... */ }
}
```

## How to fix

- Identify distinct responsibilities and extract them into separate classes or services.
- Group related data and behavior together.
- Keep class names specific to their responsibility.

## Configuration

```yaml
rules:
  E0027:
    max_methods: 15
    max_fields: 10
```
