# E0021: Number of Children (NOC)

Number of Children (NOC) counts how many classes directly extend a given class.

## Why it matters

A base class with many direct subclasses can become fragile. Changes to that base class may affect many descendants, increasing the risk of unintended breakage.

## How it works

The rule counts classes that directly declare `extends YourClass`.

If the number of direct children exceeds the configured `max_children`, the rule reports a violation.

## Bad example

```php
// NOC is 16 in this example.
class BaseController {}

class UserController extends BaseController {}
class PostController extends BaseController {}
class CommentController extends BaseController {}
// ... and 13 more controllers ...
```

## Good example

```php
// Prefer composition when shared behavior does not require inheritance.
class ResponseFactory {
    public function json($data) { /* ... */ }
}

class UserController {
    public function __construct(private ResponseFactory $response) {}
}
```

## How to fix

- Avoid using a single base class as a catch-all for shared behavior.
- Prefer composition or dependency injection for reusable functionality.
- Split large base classes into smaller, focused abstractions when inheritance is needed.

## Configuration

```yaml
rules:
  E0021:
    max_children: 15
```
