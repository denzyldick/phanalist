# E0018: Weighted Methods per Class (WMC)

Weighted Methods per Class (WMC) measures the total complexity of a class by summing the cyclomatic complexity of its methods.

## Why it matters

Even if individual methods are manageable, a class can still be difficult to maintain when it contains too much total complexity. A high WMC score often indicates that a class has too many responsibilities.

## How it works

The rule calculates cyclomatic complexity (see E0009) for each method in the class and adds the scores together.

Example:

- Method A: 5
- Method B: 2
- Method C: 15
- Total WMC: 22

If the total exceeds the configured `max_wmc`, the rule reports a violation.

## Bad example

```php
class ReportGenerator {
    public function parseData(): void {
        // ... many branches and loops ...
    }

    public function validateData(): void {
        // ... many branches and loops ...
    }

    public function transformData(): void {
        // ... many branches and loops ...
    }

    public function exportData(): void {
        // ... many branches and loops ...
    }
    // Total WMC may exceed the configured limit.
}
```

## Good example

```php
class ReportGenerator {
    public function __construct(
        private DataParser $parser,
        private DataValidator $validator,
        private DataTransformer $transformer,
        private DataExporter $exporter
    ) {}

    public function generate(): void {
        $data = $this->parser->parse();
        $this->validator->validate($data);
        $transformed = $this->transformer->transform($data);
        $this->exporter->export($transformed);
    }
}
```

## How to fix

- Split complex behavior into smaller, specialized classes.
- Move heavy methods to collaborators that own the related responsibility.
- Keep each class focused on a narrow set of tasks.

## Configuration

```yaml
rules:
  E0018:
    max_wmc: 50
```
