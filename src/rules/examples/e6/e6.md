# E0006: Property modifiers

Class properties should declare an explicit visibility modifier: `public`, `protected`, or `private`.

## Why it matters

Explicit visibility makes it clear how a property is intended to be used. Using `private` or `protected` can also help protect internal state by limiting direct external access.

## Bad example

```php
class User {
    // Missing visibility modifier.
    string $name;
}
```

## Good example

```php
class User {
    private string $name;

    public function getName(): string {
        return $this->name;
    }
}
```

## What it checks

- Class properties that do not declare an explicit visibility modifier.

## When it does not report

- When properties declare `private`, `protected`, or `public`.

## How to fix

Add an explicit visibility modifier to each property. Choose `private` or `protected` when you want to control access through methods.

## Configuration

E0006 has no configuration options and is enabled by default.
