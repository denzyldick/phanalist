# E0041: Unreachable Code

E0041 reports statements that cannot be reached. It is the unreachable-code
member of Phanalist's bounded formal verification family (E0031-E0043). The
family shares a Z3-backed engine that encodes path conditions and values.

## What it checks

- Statements after `return`, `break`, `continue`, `throw`, or `exit`
- Numbered `break` and `continue` levels
- `continue` inside `switch`
- Unreachable statements after `never`-returning calls
- Conditional throws and exits that only make one branch unreachable
- Statements after exhaustive `switch` or `match` constructs

## Model limits

E0041 shares the model limits, loop bounds, and interprocedural behavior
described in [E0031](../e31/e31.md). A branch that merely throws is not treated as
making the whole following statement unreachable.

```yaml
    php_version: "8.4"
    check_division: true
    check_modulo: true
    check_intdiv: true
    check_array_index: true
    check_string_offset: true
    check_nullability: true
    check_types: true
    check_assertions: true
    check_unreachable: true
    check_return_contracts: true
    loop_strategy: auto
    unroll_depth: 16
    timeout_ms: 1000
    unknown_policy: report
    max_findings_per_function: 50
```

See [E0031](../e31/e31.md) for the shared model limits, `unknown_policy` behavior, and
the backward-compatible `E0031` enable/disable expansion.
