# E0024: Lines of Code per Method

Reports concrete methods whose body exceeds the configured line-count threshold.

## Why it matters

Long methods are harder to read, test, and change safely. Splitting a method into smaller, focused methods usually makes behavior easier to understand and reuse.

## What it checks

- Concrete method bodies in classes, traits, and enums.
- Lines of code are counted as `end_line - start_line - 1` for the method body.
- A method is reported when its LOC is greater than `max_loc`.

## Bad example

This method tries to do everything in one place.

```php
public function processOrder(Order $order): void
{
    $this->validate($order);
    $this->checkStock($order);
    // ... 50 more lines doing shipping, billing, notifications ...
    $this->sendConfirmation($order);
}
```

## Good example

Each method has a focused responsibility.

```php
public function processOrder(Order $order): void
{
    $this->validate($order);
    $this->processPayment($order);
    $this->ship($order);
    $this->notify($order);
}

private function processPayment(Order $order): void { /* 5 lines */ }
private function ship(Order $order): void { /* 8 lines */ }
private function notify(Order $order): void { /* 6 lines */ }
```

## How to fix

- Extract cohesive blocks into private/helper methods with descriptive names.
- Separate validation, orchestration, and side effects when possible.
- Keep the top-level method focused on the main workflow.

## Configuration

```yaml
rules:
  E0024:
    max_loc: 50
```
