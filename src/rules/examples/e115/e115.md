# E0115: XXE via libxml

Parsing XML from untrusted input with libxml functions can allow XML External Entity (XXE) attacks when external entities are resolved.

## Why it matters

XXE vulnerabilities can:
- Expose local files such as `/etc/passwd`, source code, or credentials
- Trigger server-side request forgery (SSRF) against internal services
- Cause denial of service through entity expansion

## Bad example

```php
$xml = $_GET['xml'] ?? '';
$doc = new DOMDocument();
$doc->loadXML($xml, LIBXML_NOENT); // resolves external entities
// or
$xml = simplexml_load_string($xml); // external entities resolved by default
```

## Good example

```php
libxml_disable_entity_loader(true); // PHP < 8.0
$doc = new DOMDocument();
$doc->loadXML($xml, LIBXML_NONET | LIBXML_NOWARNING);
// PHP 8.0+: use XMLReader which doesn't resolve external entities by default
$reader = new XMLReader();
$reader->xml($xml);
```

## What it checks

- `simplexml_load_string()`, `DOMDocument::loadXML()`, `DOMDocument::load()` with tainted input and `LIBXML_NOENT`, or without `LIBXML_NONET`
- `xml_parser_create()` / `xml_parse()` with default entity handling

## When it does not report

- `libxml_disable_entity_loader(true)` is recognized as mitigation (legacy PHP)
- `LIBXML_NONET` is recognized as disabling network access

## How to fix

1. Call `libxml_disable_entity_loader(true)` before parsing on PHP versions before 8.0.
2. Use `LIBXML_NONET` to block network access during parsing.
3. Prefer JSON over XML for user-supplied data when possible.
4. Consider `XMLReader`, which does not resolve external entities by default in PHP 8.0+.

## Configuration

E0115 is enabled by default.

```yaml
rules:
  E0115:
    unsafe_functions:
      - simplexml_load_string
      - simplexml_load_file
      - DOMDocument::loadXML
      - DOMDocument::load
      - XMLReader::open
      - XMLReader::xml
    safe_flags:
      - LIBXML_NONET
      - LIBXML_NOWARNING
      - LIBXML_NSCLEAN
    unsafe_flags:
      - LIBXML_NOENT
```
