# E0114: PHP info disclosure

**In plain English:** `phpinfo()` is called in committed production code, exposing detailed PHP configuration, version, extensions, and environment variables to anyone who can access that page.

**Why it matters:** Attackers use `phpinfo()` output to:
- Fingerprint the server (PHP version, loaded extensions)
- Find version-specific vulnerabilities
- Read environment variables and configuration values
- Plan targeted attacks against your infrastructure

## Bad

```php
<?php phpinfo(); ?>
```

## Good

```php
// Remove phpinfo() entirely from production code
// Use it only in local development, never commit it
```

## What the rule checks

- `phpinfo()` function calls anywhere in committed source code
- `phpinfo(INFO_ALL)` or `phpinfo(INFO_GENERAL)` etc.

## When it does not report

- No safe usage — `phpinfo()` is always flagged in committed code

## How to fix

1. Remove `phpinfo()` from production code
2. Use it only in local development, never commit it
3. If needed temporarily, protect with IP allowlist + authentication and delete after use

## Configuration

E0114 is enabled by default and has no configuration options.
