# E0114: PHP Info Disclosure

Calling `phpinfo()` in committed production code exposes detailed PHP configuration, version, extensions, and environment variables to anyone who can access the page.

## Why it matters

Attackers can use `phpinfo()` output to:

- Fingerprint the server (PHP version, loaded extensions)
- Find version-specific vulnerabilities
- Read environment variables and configuration values
- Plan targeted attacks against your infrastructure

## Bad example

```php
<?php phpinfo(); ?>
```

## Good example

```php
// Remove phpinfo() entirely from production code
// Use it only in local development, never commit it
```

## What it checks

- `phpinfo()` function calls anywhere in committed source code
- `phpinfo(INFO_ALL)`, `phpinfo(INFO_GENERAL)`, and similar calls

## When it does not report

- There is no safe usage; `phpinfo()` is always flagged in committed code

## How to fix

1. Remove `phpinfo()` from production code.
2. Use it only in local development and do not commit it.
3. If it is needed temporarily, protect it with an IP allowlist and authentication, then delete it after use.

## Configuration

E0114 is enabled by default and has no configuration options.
