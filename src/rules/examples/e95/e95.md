# E0095: Dynamic Property Access

**In plain English:** Your code accesses object properties using a name from user input. An attacker can read or write arbitrary object properties, bypassing encapsulation.

**Why it matters:** Dynamic property access can:
- Read sensitive object properties
- Modify internal object state
- Bypass encapsulation and access controls

## Bad

```php
$prop = $_GET['prop'] ?? '';
$value = $obj->$prop;
$obj->$prop = $_GET['value'];
```

## Good

```php
$prop = $_GET['prop'] ?? '';
$allowed = ['name', 'email'];
if (!in_array($prop, $allowed, true)) {
    http_response_code(400);
    exit;
}
$value = $obj->$prop;
```

## What the rule checks

- `$obj->$prop` where `$prop` is a variable (read)
- `$obj->$prop = $value` where `$prop` is a variable (write) — covered by E0054
- `$$var` variable variables where `$var` is tainted (covered by E0054)

## When it does not report

- Whitelist validation is recognized
- Static property access is not flagged

## How to fix

1. Use a whitelist of allowed property names
2. Use explicit getter/setter methods

## Configuration

E0095 is enabled by default and has no configuration options.
