# E0108: XXE (XML External Entity)

**In plain English:** XML parsers are configured to resolve external entities. An attacker can include `file:///etc/passwd` or make outbound requests from your server.

**Why it matters:** XXE can lead to:
- Local file disclosure (`/etc/passwd`, source code, credentials)
- SSRF (Server-Side Request Forgery)
- Port scanning
- Denial of service

## Bad

```php
$xml = $_GET['xml'] ?? '';
$doc = new DOMDocument();
$doc->loadXML($xml, LIBXML_NOENT); // resolves external entities
// or
$xml = simplexml_load_string($xml); // external entities enabled by default
```

## Good

```php
libxml_disable_entity_loader(true); // disable globally (PHP < 8.0)
$doc = new DOMDocument();
$doc->loadXML($xml, LIBXML_NONET | LIBXML_NOWARNING);
// For PHP 8.0+: use XMLReader or set libxml options per-parser
$reader = new XMLReader();
$reader->xml($xml);
```

## What the rule checks

- `simplexml_load_string()`, `DOMDocument::loadXML()`, `DOMDocument::load()` with tainted input and `LIBXML_NOENT` or without `LIBXML_NONET`
- `XMLReader::open()` / `XMLReader::xml()` with external entity resolution enabled
- `xml_parser_create()` / `xml_parse()` with default entity handling

## When it does not report

- `libxml_disable_entity_loader(true)` is recognized as mitigation (PHP < 8.0)
- `LIBXML_NONET` flag is recognized as network-disabled
- Cannot determine entity loader state at runtime across files

## How to fix

1. Call `libxml_disable_entity_loader(true)` before parsing (legacy PHP)
2. Use `LIBXML_NONET | LIBXML_NOENT` carefully — `NOENT` enables entities, `NONET` blocks network
3. Prefer JSON over XML for user-supplied data formats
4. Use XMLReader which doesn't resolve external entities by default

## Configuration

E0108 is enabled by default. Configuration options:

```yaml
rules:
  E0108:
    unsafe_functions:
      - simplexml_load_string
      - simplexml_load_file
      - DOMDocument::loadXML
      - DOMDocument::load
      - XMLReader::open
      - XMLReader::xml
    safe_flags:
      - LIBXML_NONET
      - LIBXML_NOWARNING
      - LIBXML_NSCLEAN
    unsafe_flags:
      - LIBXML_NOENT  # enables entity resolution
```

XXE. Classic XML vulnerability. Less common in modern PHP but still present in SOAP/XML-RPC APIs.
