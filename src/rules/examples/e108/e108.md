# E0108: Dynamic instantiation

**In plain English:** A class is instantiated using a name that comes from user input, allowing an attacker to instantiate any autoloadable class, potentially leading to object injection.

**Why it matters:** Combined with gadget chains, dynamic class instantiation can:
- Instantiate any autoloadable class
- Trigger object injection via magic methods
- Lead to remote code execution

## Bad

```php
$class = $_GET['class'] ?? '';
$obj = new $class();
```

## Good

```php
$class = $_GET['class'] ?? '';
$allowed = ['User', 'Product', 'Order'];
if (!in_array($class, $allowed, true)) {
    http_response_code(400);
    exit;
}
$obj = new $class();
```

## What the rule checks

- `new $class()` where `$class` comes from superglobal array access
- `ReflectionClass::newInstanceArgs()` with tainted class name
- `class_exists()` followed by instantiation of user-controlled class names

## When it does not report

- Whitelist-validated class names
- Static class names

## How to fix

1. Use a whitelist of allowed class names
2. Use a factory pattern instead of dynamic instantiation
3. Never instantiate classes based directly on user input

## Configuration

E0108 is enabled by default and has no configuration options.

## Taint Engine Backed

This rule is now powered by the phanalist taint engine. Instead of guessing whether
a variable contains user input (`has_user_input` / `looks_dynamic` heuristics), the
engine performs source-to-sink taint tracking. The rule queries `SinkKind` from the
engine:

- **`TaintMode::Only`** (default): Only reports when a proven taint flow from a source
  (e.g. `$_GET`, `$_POST`, superglobals, request parameters) reaches the sink.
- **`TaintMode::Annotate`**: Reports all findings and adds the proven source origin.
- **`TaintMode::Off`**: Retains the legacy heuristic behaviour through
  `taint_support::looks_dynamic` for compatibility.

Every finding carries structured metadata (severity, category, confidence, effort,
CWE/OWASP references, fingerprint) and a stable content-based fingerprint independent
of line numbers.
