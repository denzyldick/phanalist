# E0015: Lack of Cohesion of Methods (LCOM4)

LCOM4 measures whether the methods in a class are connected through shared properties or method calls. A higher score can indicate that a class contains unrelated responsibilities.

## Why it matters

A class with low cohesion often does more than one job. Splitting it into focused classes can make behavior easier to understand, test, and change.

## How it works

LCOM4 counts connected "islands" of methods and properties in a class:

1. Methods that use the same property are connected.
2. Methods that call each other are connected.
3. Methods that are not connected form separate islands.

A score of `1` means the class is cohesive. A score of `2` or higher means the class contains separate groups of logic that may belong in different classes.

## Bad example (score: 2)

```php
class UserManager {
    private $db;
    private $logger;

    // Island 1: database work
    public function saveUser($user) {
        $this->db->save($user);
    }

    // Island 2: logging work
    public function logError($message) {
        $this->logger->write($message);
    }
}
```

A possible fix is to split this into separate classes, such as `UserRepository` and `ErrorLogger`.

## Good example (score: 1)

```php
class Counter {
    private $count = 0;

    public function increment() {
        $this->count++;
    }

    public function getCount() {
        return $this->count;
    }
}
```

Both methods use the same property, so they belong to the same cohesive class.

## How to fix

- Split unrelated responsibilities into separate classes.
- Move methods next to the data they operate on.
- Keep classes focused on one clear purpose.

## Configuration

```yaml
rules:
  E0015:
    threshold: 1
```
