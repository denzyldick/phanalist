# E0000: Example rule

This is the template rule used by the "Adding a new rule" tutorial. It never reports a violation.

## Why it matters

It shows the smallest complete rule implementation. It is not intended for real analysis.

## Bad example

```php
<?php
// E0000 is a placeholder rule and should not report real issues.
function example(): void {}
```

## Good example

```php
<?php
// Use a real rule code in configuration and rule docs.
function example(): void {}
```

## What it checks

Nothing. The `validate()` method always returns an empty list.

## When it does not report

Always.

## How to fix

There is nothing to fix. When creating a new rule, copy this rule and replace its code, description, validation logic, examples, and documentation.

## Configuration

E0000 has no configuration options. It is registered with the other rules but does not produce findings.
