# E0000: Example Rule

**In plain English:** This is the template rule used by the “Adding a new rule”
tutorial. It never reports a violation.

**Why it matters:** It shows the smallest complete rule implementation and is
not meant to be enabled for real analysis.

## What it checks

Nothing. The `validate()` method always returns an empty list.

## When it does not report

Always.

## How to fix

There is nothing to fix. Copy the rule when creating a new rule, then replace
its code, description, validation logic, examples, and documentation.

## Configuration

E0000 has no configuration options. It is registered with the other rules but
does not produce findings.
