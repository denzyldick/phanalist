# E0081: Deprecated regex function

POSIX regex functions such as `ereg()` and `split()` are deprecated and were removed in PHP 7.0. Use the `preg_*()` family or `explode()` instead.

## Why it matters

Using removed functions causes fatal errors on PHP 7.0 and later, which breaks the application. The `preg_*()` functions are more capable and actively maintained.

## Bad example

```php
if (ereg("^[a-zA-Z]+$", $username)) { // deprecated, removed in PHP 7.0
    // valid
}
$parts = split(":", $data); // deprecated, removed in PHP 7.0
```

## Good example

```php
if (preg_match("/^[a-zA-Z]+$/", $username)) {
    // valid
}
$parts = explode(":", $data); // or preg_split("/:/", $data)
```

## What it checks

- `ereg()`, `ereg_replace()`, `eregi()`, and `eregi_replace()` calls
- `split()` and `spliti()` calls

## When it does not report

- `preg_match()`, `preg_replace()`, `preg_split()`, and `explode()` are not flagged

## How to fix

1. Replace `ereg()` with `preg_match()`.
2. Replace `ereg_replace()` with `preg_replace()`.
3. Replace `split()` with `explode()` or `preg_split()`.

## Configuration

E0081 is enabled by default and has no configuration options.
