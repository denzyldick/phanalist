# E0081: Deprecated regex function

**In plain English:** Deprecated POSIX regex functions `ereg()` and `split()` are used instead of the modern `preg_*()` family. These functions were removed in PHP 7.0.

**Why it matters:** Using removed functions causes fatal errors on PHP 7.0+, breaking your application entirely. The `preg_*()` functions are more powerful and actively maintained.

## Bad

```php
if (ereg("^[a-zA-Z]+$", $username)) { // deprecated, removed in PHP 7.0
    // valid
}
$parts = split(":", $data); // deprecated, removed in PHP 7.0
```

## Good

```php
if (preg_match("/^[a-zA-Z]+$/", $username)) {
    // valid
}
$parts = explode(":", $data); // or preg_split("/:/", $data)
```

## What the rule checks

- `ereg()`, `ereg_replace()`, `eregi()`, `eregi_replace()` calls
- `split()`, `spliti()` calls

## When it does not report

- `preg_match()`, `preg_replace()`, `preg_split()`, `explode()` are not flagged

## How to fix

1. Replace `ereg()` with `preg_match()`
2. Replace `ereg_replace()` with `preg_replace()`
3. Replace `split()` with `explode()` or `preg_split()`

## Configuration

E0081 is enabled by default and has no configuration options.
