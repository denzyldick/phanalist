# E0062: Command injection

This rule reports shell command calls where user-controlled input reaches the command argument. An attacker may be able to inject additional shell syntax or commands.

## Why it matters

Command injection can allow arbitrary command execution on the server, which may lead to data exposure, data loss, or full system compromise.

## Bad example

```php
$file = $_GET['file'] ?? '';
system("cat $file");
```

If an attacker visits `?file=; rm -rf /var/www/html`, the shell may interpret the injected command.

## Good example

```php
// Prefer PHP APIs instead of shell commands
$content = file_get_contents($file);

// If shell execution is unavoidable, validate and escape
$allowed = ['file1.txt', 'file2.txt'];
if (!in_array($file, $allowed, true)) {
    http_response_code(400);
    exit;
}
$file = escapeshellarg($file);
system("cat $file");
```

## What it checks

- Shell execution functions such as `system()`, `exec()`, `shell_exec()`, `passthru()`, `popen()`, and `proc_open()`
- Cases where user-controlled input reaches the command argument, based on taint analysis and dynamic-expression heuristics

## When it does not report

- Commands with literal string arguments only
- Commands where input has been sanitized in ways recognized by the analysis, such as `escapeshellarg()`
- Cases where the taint or heuristic model cannot prove the input reaches the command

## How to fix

- Avoid shell execution when a PHP built-in function can do the job.
- If shell execution is necessary, validate input against a strict allowlist.
- Use `escapeshellarg()` for user-controlled arguments and `escapeshellcmd()` carefully when escaping a full command string is appropriate.
- Do not pass raw request data to shell commands.

## Configuration

E0062 is enabled by default. The taint-aware behavior is controlled by a per-rule `taint_mode` setting:

```yaml
rules:
  E0062:
    taint_mode: annotate
```

- `annotate` (default) reports the finding and adds the proven source origin to the message.
- `only` reports only findings reached by proven tainted data.
- `off` keeps the legacy heuristic-only behavior.
