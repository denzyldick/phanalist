# E0025: Lines of Code per File

Reports files that exceed the configured total line-count threshold.

## Why it matters

Very large files are harder to navigate and often contain too many responsibilities. Smaller files with clear boundaries are usually easier to review and maintain.

## What it checks

- Applies to files containing a class, trait, enum, or interface declaration.
- Counts every line in the file (`file.lines.len()`).
- Reports when the total line count is greater than `max_loc`.

## Bad example

One file contains multiple responsibilities.

```php
<?php

namespace App;

class OrderManager
{
    // 300 lines of order logic...
    // 200 lines of billing logic...
    // 150 lines of shipping logic...
}
```

## Good example

Responsibilities are split into smaller files.

```php
<?php

namespace App;

class OrderProcessor
{
    // ~50 lines
}
```

## How to fix

- Split large files by responsibility, feature, or domain concept.
- Move related helpers into dedicated classes or modules.
- Keep each file focused on a single primary purpose.

## Configuration

```yaml
rules:
  E0025:
    max_loc: 500
```
