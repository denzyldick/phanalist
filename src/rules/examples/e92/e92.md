# E0092: XML External Entity (XXE)

Parsing XML from untrusted input without disabling external entity resolution can allow an attacker to read local files or make outbound requests from your server.

## Why it matters

- Local file disclosure (for example `/etc/passwd`, source code, or credentials)
- Server-Side Request Forgery (SSRF) against internal services
- Port scanning of internal networks
- Denial of service

## Bad example

```php
$xml = $_GET['xml'] ?? '';
$doc = new DOMDocument();
$doc->loadXML($xml, LIBXML_NOENT); // resolves external entities
// or
$xml = simplexml_load_string($xml); // external entities resolved by default
```

## Good example

```php
libxml_disable_entity_loader(true); // PHP < 8.0
$doc = new DOMDocument();
$doc->loadXML($xml, LIBXML_NONET | LIBXML_NOWARNING);
// For PHP 8.0+: use XMLReader which doesn't resolve external entities by default
$reader = new XMLReader();
$reader->xml($xml);
```

## What it checks

- `simplexml_load_string()`, `DOMDocument::loadXML()`, and `DOMDocument::load()` with tainted input and `LIBXML_NOENT`, or without `LIBXML_NONET`
- `xml_parser_create()` / `xml_parse()` with default entity handling

## When it does not report

- `libxml_disable_entity_loader(true)` is recognized as mitigation (legacy PHP)
- `LIBXML_NONET` is recognized as network-disabled parsing
- Entity loader state cannot be determined at runtime across files

## How to fix

1. Call `libxml_disable_entity_loader(true)` before parsing on legacy PHP versions.
2. Use `LIBXML_NONET` to block network access during parsing.
3. Prefer JSON over XML for user-supplied data formats when possible.
4. Use `XMLReader`, which does not resolve external entities by default.

## Configuration

E0092 is enabled by default.

```yaml
rules:
  E0092:
    unsafe_functions:
      - simplexml_load_string
      - simplexml_load_file
      - DOMDocument::loadXML
      - DOMDocument::load
      - XMLReader::open
      - XMLReader::xml
    safe_flags:
      - LIBXML_NONET
      - LIBXML_NOWARNING
      - LIBXML_NSCLEAN
    unsafe_flags:
      - LIBXML_NOENT  # enables entity resolution
```
