# E0135: PHP info disclosure

Calling `phpinfo()` in committed code exposes detailed PHP configuration and environment information.

## Why it matters

`phpinfo()` output can reveal:
- PHP version, loaded extensions, and server configuration
- Environment variables and configuration values
- Information that helps attackers identify version-specific weaknesses and plan targeted attacks

## Bad example

```php
<?php phpinfo(); ?>
```

## Good example

```php
// Remove phpinfo() entirely from production code.
// Use it only in local development and do not commit it.
```

## What it checks

- `phpinfo()` function calls anywhere in committed source code
- `phpinfo(INFO_ALL)`, `phpinfo(INFO_GENERAL)`, and other `phpinfo(...)` variants

## When it does not report

- There are no safe usages; `phpinfo()` is always flagged in committed code.

## How to fix

1. Remove `phpinfo()` from production code.
2. Use it only in local development, and do not commit it.
3. If temporary access is required, protect it with strict access controls and remove it immediately after use.

## Configuration

E0135 is enabled by default and has no configuration options.
