Method parameters count

Methods with many parameters can be hard to read, call, and change.

Try in Playground All rules GitHub

Methods with many parameters can be hard to read, call, and change.

Why it matters

A long parameter list often means a method is handling too many responsibilities or missing an abstraction. Reducing parameter count can make the method's purpose clearer and reduce the chance of passing arguments in the wrong order.

Bad example

<?php

class Maintenance
{
    public function execute(
        Hammer $hammer,
        Screw $screw,
        Screwdriver $screwDriver,
        Nails $nails,
        Paint $paint,
        SandingPaper $sandingPaper,
        Painting $painting,
        Brush $brush,
        Ladder $ladder
    ) {
    }
}

Good example

Group related behavior into objects or value objects so the method accepts a smaller, clearer set of inputs.

<?php

interface Activity
{
    /** @return array<int, object> */
    public function getTools(): array;
}

class Maintenance
{
    public function execute(Activity ...$activities): void
    {
        foreach ($activities as $activity) {
            $tools = $activity->getTools();
            // Use tools.
        }
    }
}

class Paint implements Activity
{
    public function getTools(): array
    {
        return [];
    }
}

This is one possible refactor. The right solution depends on the method's behavior, but the goal is to keep method signatures focused and manageable.

What it checks

  • The number of parameters declared by a method.
  • By default, constructors are included.
  • The default maximum is 8 parameters.

When it does not report

  • When the parameter count is within the configured max_parameters limit.
  • When check_constructor is false, constructor parameter counts are not checked.

How to fix

  • Group related parameters into a dedicated object or value object.
  • Split the method into smaller methods with clearer responsibilities.
  • Pass a collection or domain object when several parameters represent the same concept.
