Invalid builtin argument

This rule reports builtin calls whose literal arguments are invalid and would make PHP throw a `ValueError` at runtime.

Try in Playground All rules GitHub

This rule reports builtin calls whose literal arguments are invalid and would make PHP throw a ValueError at runtime.

Why it matters

These argument errors fail at runtime, often on a specific code path. Catching them statically avoids avoidable crashes and makes the intended input constraints explicit.

Bad example

<?php
function bad(array $items): array
{
    return array_chunk($items, 0); // invalid size
}

Good example

<?php
function good(array $items): array
{
    return array_chunk($items, 2);
}

What it checks

  • str_repeat() with a negative repeat count
  • array_fill() with a negative count
  • range() with a zero step
  • str_split() and mb_str_split() with a non-positive chunk length
  • explode() with an empty delimiter
  • array_chunk() with a non-positive chunk size
  • array_combine() with literal arrays of different lengths
  • random_int(), mt_rand(), and rand() with a minimum greater than the maximum

The rule only reports values it can prove from literals, including unary minus, parenthesized literals, and literal array lengths. Non-literal arguments are ignored so the rule does not duplicate runtime type analysis.

When it does not report

  • Only direct calls to the named builtins are checked.
  • Named arguments are matched by their source order, not by parameter name.
  • Array lengths are known only for literal arrays without missing or variadic elements.
  • Integer values that do not fit in i64 are ignored.
  • The rule does not evaluate constants, class constants, or expressions.

How to fix

  • Pass arguments that satisfy the builtin's documented constraints.
  • For counts and lengths, use zero or positive values as required.
  • For range(), use a non-zero step.
  • For array_combine(), ensure both arrays have the same length.
  • For random ranges, ensure the minimum is less than or equal to the maximum.

Configuration

E0049 has no configuration options and is enabled by default.
