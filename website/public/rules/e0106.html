E0106 security critical

Deserialization of Untrusted Data

Deserializing untrusted data using `unserialize()` or `wddx_deserialize()` can instantiate arbitrary PHP objects and trigger magic methods, leading to object injection.

Deserializing untrusted data using unserialize() or wddx_deserialize() can instantiate arbitrary PHP objects and trigger magic methods, leading to object injection.

Why it matters

Deserialization of untrusted data is a critical vulnerability. Attackers can:

  • Instantiate arbitrary PHP classes
  • Trigger magic methods (__wakeup(), __destruct())
  • Execute arbitrary code through gadget chains
  • Achieve remote code execution

Bad example

$data = $_GET['data'] ?? '';
$result = unserialize($data);
// or
$result = wddx_deserialize($data);

Good example

// Use JSON instead of PHP serialization or WDDX for untrusted data
$data = $_GET['json'] ?? '';
$result = json_decode($data, true);
if (json_last_error() !== JSON_ERROR_NONE) {
    http_response_code(400);
    exit;
}

What it checks

  • unserialize() calls with tainted input from superglobals
  • wddx_deserialize() calls with any argument (inherently dangerous)
  • session_decode() with user-controlled data

When it does not report

  • unserialize() with ['allowed_classes' => false] to prevent object instantiation
  • json_decode() is recognized as safe

How to fix

  1. Never pass user-controlled data to unserialize() or wddx_deserialize().
  2. Use JSON (json_decode() / json_encode()) instead.
  3. If unserialize() is unavoidable, pass ['allowed_classes' => false].

Configuration

E0106 is enabled by default and has no configuration options.

Taint engine

This rule is backed by the phanalist taint engine. Instead of guessing whether a variable contains user input, the engine tracks taint from sources to sinks.

  • TaintMode::Only (default): Reports only when a proven taint flow from a source (for example $_GET, $_POST, superglobals, or request parameters) reaches the sink.
  • TaintMode::Annotate: Reports all findings and adds the proven source origin.
  • TaintMode::Off: Retains legacy heuristic behavior through taint_support::looks_dynamic for compatibility.

Every finding carries structured metadata (severity, category, confidence, effort, CWE/OWASP references, fingerprint) and a stable content-based fingerprint independent of line numbers.
