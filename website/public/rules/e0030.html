Cyclomatic Complexity Density

Reports methods where decision-making logic is densely packed into a small number of lines.

Try in Playground All rules GitHub

Reports methods where decision-making logic is densely packed into a small number of lines.

Why it matters

Cyclomatic complexity density measures how much branching occurs per line of code. A short method can still be difficult to understand if most lines contain decisions.

What it checks

  • Applies to concrete methods in classes, traits, and enums.
  • Computes density = (1 + total_branches) / body_lines.
  • Branches include if, elseif, case, catch, and loops (for, foreach, while, do-while).
  • Reports when density is greater than max_density.

Bad example

The method is short, but most lines contain branching.

public function resolve($a, $b, $c): int
{
    if ($a) { if ($b) { return 1; } else { if ($c) { return 2; } } }
    if ($a && $b || $c) { return 3; }
    if (!$a) { return 4; }
    return 0;
}

Good example

The same logic is spread out so each decision is easier to follow.

public function resolve($a, $b, $c): int
{
    if ($a && $b) {
        return 1;
    }
    if ($a && $c) {
        return 2;
    }
    if ($a || $c) {
        return 3;
    }
    if (!$a) {
        return 4;
    }
    return 0;
}

How to fix

  • Split dense logic into smaller methods with clear names.
  • Use early returns to reduce nesting.
  • Separate complex conditions into well-named intermediate expressions where it improves readability.
