E0084 security critical

SQL query string concatenation

Concatenating user input directly into SQL query strings can allow attackers to inject arbitrary SQL and read, modify, or delete database data.

Concatenating user input directly into SQL query strings can allow attackers to inject arbitrary SQL and read, modify, or delete database data.

Why it matters

SQL injection is a serious vulnerability. It can lead to:

  • Theft of user data (such as emails, passwords, or payment information)
  • Authentication bypass
  • Database modification or deletion
  • Broader server compromise in some environments

Bad example

$id = $_GET['id'] ?? '';
$result = mysqli_query($conn, "SELECT * FROM users WHERE id = $id");

An attacker can visit ?id=1 OR 1=1, turning the query into:

SELECT * FROM users WHERE id = 1 OR 1=1

This returns all users instead of just one.

Good example

$id = $_GET['id'] ?? '';
$stmt = $pdo->prepare("SELECT * FROM users WHERE id = ?");
$stmt->execute([$id]);
$user = $stmt->fetch();

With prepared statements, the database treats $id as data, not executable SQL.

What it checks

  • mysqli_query(), mysqli::query(), pg_query(), pg_exec(), PDO::query(), and PDO::exec() calls
  • Cases where user input ($_GET, $_POST, $_REQUEST, $_COOKIE, etc.) is concatenated directly into the SQL string

When it does not report

  • Prepared statements with ? or :name placeholders (for example, $pdo->prepare("... WHERE id = ?"))
  • Static SQL queries with no user input
  • Input that has been validated against a whitelist

How to fix

  1. Treat $_GET, $_POST, $_REQUEST, $_COOKIE, and similar sources as untrusted input.
  2. Use prepared statements with PDO or MySQLi. Do not concatenate variables into SQL strings.
  3. Validate input as an additional safeguard (for example, cast to int when expecting a number).
// Bad
$query = "SELECT * FROM users WHERE id = " . $_GET['id'];

// Good
$stmt = $pdo->prepare("SELECT * FROM users WHERE id = ?");
$stmt->execute([$_GET['id']]);

Configuration

E0084 is enabled by default and has no configuration options.
