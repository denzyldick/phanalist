E0100 security major

Variable Function Call

Calling a function using a name that comes from user input can allow an attacker to invoke arbitrary PHP functions on your server.

Try in Playground All rules GitHub

Calling a function using a name that comes from user input can allow an attacker to invoke arbitrary PHP functions on your server.

Why it matters

Variable function calls allow dynamic code execution when the function name is controllable by an attacker:

  • Arbitrary PHP functions can be called
  • Dangerous system functions like system(), exec(), or shell_exec() may be reachable
  • Access controls may be bypassed

Bad example

$func = $_GET['func'] ?? '';
$func();
call_user_func($func, $arg);

Good example

$func = $_GET['func'] ?? '';
$allowed = ['strlen', 'md5', 'sha1'];
if (!in_array($func, $allowed, true)) {
    http_response_code(400);
    exit;
}
$func($input);

What it checks

  • $func() where $func is assigned from tainted superglobals
  • call_user_func($func, ...) where $func is tainted
  • call_user_func_array($func, ...) where $func is tainted

When it does not report

  • Allowlist validation is recognized
  • Static function names are not flagged

How to fix

  1. Use an allowlist or dispatch table of permitted functions.
  2. Never call user-supplied function names directly.

Configuration

E0100 is enabled by default and has no configuration options.

Taint engine

This rule is backed by the phanalist taint engine. Instead of guessing whether a variable contains user input, the engine tracks taint from sources to sinks.

  • TaintMode::Only (default): Reports only when a proven taint flow from a source (for example $_GET, $_POST, superglobals, or request parameters) reaches the sink.
  • TaintMode::Annotate: Reports all findings and adds the proven source origin.
  • TaintMode::Off: Retains legacy heuristic behavior through taint_support::looks_dynamic for compatibility.

Every finding carries structured metadata (severity, category, confidence, effort, CWE/OWASP references, fingerprint) and a stable content-based fingerprint independent of line numbers.
