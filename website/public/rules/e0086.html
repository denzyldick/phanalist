E0086 security minor

Deprecated session function

Deprecated session functions `session_register()`, `session_is_registered()`, and `session_unregister()` were removed in PHP 5.4. Use the `$_SESSION` superglobal instead.

Deprecated session functions session_register(), session_is_registered(), and session_unregister() were removed in PHP 5.4. Use the $_SESSION superglobal instead.

Why it matters

These functions no longer exist in PHP 5.4 and later, so code that uses them will cause fatal errors. $_SESSION is the supported way to manage session data.

Bad example

session_register('username');
$username = $_POST['username'] ?? '';
if (session_is_registered('username')) {
    // ...
}
session_unregister('username');

Good example

$_SESSION['username'] = $_POST['username'] ?? '';
if (isset($_SESSION['username'])) {
    // ...
}
unset($_SESSION['username']);

What it checks

  • session_register(), session_is_registered(), and session_unregister() function calls

When it does not report

  • $_SESSION superglobal usage is not flagged
  • session_start(), session_destroy(), and session_regenerate_id() are not flagged

How to fix

  1. Replace session_register('var') with $_SESSION['var'] = ....
  2. Replace session_is_registered('var') with isset($_SESSION['var']).
  3. Replace session_unregister('var') with unset($_SESSION['var']).

Configuration

E0086 is enabled by default and has no configuration options.
