Return Contract Violation

Reports return values that contradict a declared return contract.

Try in Playground All rules GitHub

Reports return values that contradict a declared return contract.

Why it matters

A return value that violates a native type or PHPDoc @return contract can cause runtime type errors or break callers that rely on the documented contract. This rule uses Phanalist's bounded formal verification engine (Z3-backed) to detect feasible violating paths.

Bad example

<?php
/** @return int */
function countItems(array $items): int
{
    return $items; // wrong return type
}

Good example

<?php
/** @return int */
function countItems(array $items): int
{
    return count($items);
}

What it checks

  • Native return types and PHPDoc @return contracts
  • Missing return values on paths that must return a value
  • never contracts that make following code unreachable
  • Strict and weak PHP return coercion rules
  • Numeric, string, list, non-empty, and shaped array contracts
  • Generator returns are not checked against the generator return type

Model limits

E0040 shares the model limits, loop bounds, and interprocedural behavior described in E0031.

How to fix

  • Ensure every return path produces a value compatible with the declared contract.
  • Update the return type/PHPDoc when the contract is intentionally broader.
  • Add explicit guards/conversions before returning values from uncertain sources.
