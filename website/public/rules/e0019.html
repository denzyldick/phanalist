Response For a Class (RFC)

Response For a Class (RFC) measures how many distinct methods can be invoked in response to messages received by a class.

Response For a Class (RFC) measures how many distinct methods can be invoked in response to messages received by a class.

Why it matters

A high RFC score means a class interacts with many operations, either in its own methods or through external calls. This can increase the class's complexity and make changes harder to reason about.

How it works

RFC is calculated as:

  1. The number of methods declared in the class.
  2. Plus the number of unique external methods called by those methods.

For example, if a class has 5 methods and they call 3 unique external methods, the RFC score is 8. If the score exceeds the configured max_rfc, the rule reports a violation.

Bad example

class ReportProcessor {
    public function process(): void {
        Validator::check();
        $repo = new Repository();
        $repo->persist();
        $repo->flush();
        Logger::info('done');
        EventBus::dispatch();
    }
}

Good example

class FocusedProcessor {
    public function process(): void {
        $this->repository->saveAll();
        $this->notifier->notifySuccess();
    }
}

How to fix

  • Reduce the number of external calls made directly by the class.
  • Delegate detailed work to collaborators with focused responsibilities.
  • Group related operations behind a single method where appropriate.

Configuration

rules:
  E0019:
    max_rfc: 50
