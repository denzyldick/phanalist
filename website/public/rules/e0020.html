Depth of Inheritance Tree (DIT)

Depth of Inheritance Tree (DIT) measures how many parent classes a class has in its inheritance chain.

Depth of Inheritance Tree (DIT) measures how many parent classes a class has in its inheritance chain.

Why it matters

Deep inheritance hierarchies can make behavior harder to understand because methods and properties are spread across multiple classes. They also increase the risk that changes in a base class affect many descendants.

How it works

Each extends relationship increases the depth by 1.

  • class Animal {} — depth 0
  • class Dog extends Animal {} — depth 1
  • class Poodle extends Dog {} — depth 2

If the depth exceeds the configured max_depth, the rule reports a violation.

Bad example

class Model {}
class Authenticatable extends Model {}
class User extends Authenticatable {}
class StaffUser extends User {}

// Depth is 4.
class AdminUser extends StaffUser {}

Good example

interface Authenticatable {}
class Model {}

// Depth is 1. Additional behavior is composed in.
class AdminUser extends Model implements Authenticatable {
    private RolePermissions $permissions;
}

How to fix

  • Prefer composition over deep inheritance when sharing behavior.
  • Use interfaces to define capabilities.
  • Keep inheritance hierarchies shallow and focused.

Configuration

rules:
  E0020:
    max_depth: 4
