Data Class

Reports classes, traits, or enums that primarily expose data through getters/setters with little or no behavior.

Try in Playground All rules GitHub

Reports classes, traits, or enums that primarily expose data through getters/setters with little or no behavior.

Why it matters

A data-only class can push behavior into other parts of the codebase, making related logic scattered and harder to maintain. Adding meaningful behavior can improve encapsulation and clarity.

What it checks

  • Counts fields and methods in classes, traits, and enums.
  • Classifies accessor methods (get*, is*/has*, set*) using naming and simple body rules.
  • Ignores classes with no fields or fewer than min_methods methods.
  • Reports E0028:data-class when all non-constructor, non-accessor behavior is absent.
  • Reports E0028:potential-data-class when accessor ratio is >= max_getter_setter_ratio.

Bad example

This class mostly stores data and exposes getters/setters.

class UserDTO
{
    private string $name;
    private string $email;
    private int $age;

    public function getName(): string { return $this->name; }
    public function setName(string $name): void { $this->name = $name; }
    public function getEmail(): string { return $this->email; }
    public function setEmail(string $email): void { $this->email = $email; }
    public function getAge(): int { return $this->age; }
    public function setAge(int $age): void { $this->age = $age; }
}

Good example

The class includes behavior related to its own data.

class User
{
    public function __construct(
        private string $name,
        private Email $email,
        private Age $age,
    ) {}

    public function changeEmail(string $newEmail): void
    {
        if (!$this->email->isVerified()) {
            $this->email = new Email($newEmail);
        }
    }

    public function isAdult(): bool
    {
        return $this->age->value() >= 18;
    }
}

How to fix

  • Move logic that operates on the data into the class.
  • Replace simple getter/setter pairs with methods that express domain behavior when appropriate.
  • If the type is intentionally a DTO/value carrier, consider whether this rule should be tuned or disabled for that case.

Configuration

rules:
  E0028:
    max_getter_setter_ratio: 0.7
    min_methods: 3
