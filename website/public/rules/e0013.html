E0013 code-health minor

Private method not being used

This rule reports private methods that are declared in a class but never called within that class.

Try in Playground All rules GitHub

This rule reports private methods that are declared in a class but never called within that class.

Why it matters

Unused private methods are dead code. They add noise, make classes harder to understand, and can leave behind maintenance or testing overhead for logic that is no longer needed.

Bad example

class OrderProcessor {
    public function process(Order $order): void {
        $this->validateOrder($order);
    }

    private function validateOrder(Order $order): void {
        // ...
    }

    // Unused private method left over from refactoring.
    private function oldFormattingHelper(string $data): string {
        return strtoupper($data);
    }
}

Good example

class OrderProcessor {
    public function process(Order $order): void {
        $this->validateOrder($order);
    }

    private function validateOrder(Order $order): void {
        // ...
    }
}

What it checks

  • Private methods declared in a class.
  • Method calls inside the class, such as $this->methodName().
  • Reports private methods that are never referenced in the class.

When it does not report

  • When the private method is called at least once inside the class.
  • When the method is public or protected, since it may be used externally.

How to fix

  • Remove the unused private method if it is no longer needed.
  • If the method should be used, call it from the appropriate class logic.

Configuration

E0013 has no configuration options and is enabled by default.
